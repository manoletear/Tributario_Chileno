# 📚 Repositorio de Legislación Tributaria Chilena

> **Última actualización:** Febrero 2026
> **Fuentes:** BCN · SII · TTA

Este repositorio organiza la normativa tributaria vigente en Chile, incluyendo leyes fundamentales, reformas recientes, reglamentos, circulares, resoluciones, jurisprudencia administrativa y guías prácticas.

---

## 🗂️ Estructura del Repositorio

| Carpeta | Contenido |
|---|---|
| `01-leyes-fundamentales/` | Decretos Ley y Leyes base del sistema tributario chileno |
| `02-reformas-clave/` | Grandes reformas y modernizaciones (2014-2024) |
| `03-reglamentos/` | Decretos reglamentarios |
| `04-circulares/` | Instrucciones SII 2025 |
| `05-resoluciones/` | Actos administrativos SII 2025 |
| `06-oficios-jurisprudencia/` | Jurisprudencia administrativa (Oficios SII) |
| `07-guias-procedimientos/` | Guías prácticas y procedimientos clave |
