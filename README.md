# 📚 Repositorio de Legislación Tributaria Chilena

> **Última actualización:** Febrero 2026 &nbsp;|&nbsp; **Fuentes:** [BCN](https://www.bcn.cl/leychile) · [SII](https://www.sii.cl/normativa_legislacion/) · [TTA](https://www.tta.cl)

Este repositorio organiza la normativa tributaria vigente en Chile, incluyendo leyes fundamentales, reformas recientes, reglamentos, circulares, resoluciones, jurisprudencia administrativa y guías prácticas. Actualizado al **19 de febrero de 2026**.
